مطلوب تنفيذ شبكة صغيرة باستخدام برنامج Cisco Packet Tracer وتضم الأجهزة التالية: - خادم (Server): يعمل كخادم DHCP لتوزيع عناوين IP تلقائيًا، مع تفعيل خدمة DNS على نفس السيرفر. - محول (Switch): لربط الخادم وأجهزة الحاسوب الثلاثة ضمن شبكة LAN واحدة. - ثلاثة أجهزة حاسوب (PCs): متصلة بالمحول للحصول على إعدادات الشبكة تلقائيًا عبر DHCP. المهام المطلوبة: 1. إنشاء البنية الشبكية (Network Topology) باستخدام الأجهزة المذكورة مع توصيلها بكبلات Ethernet مناسبة. 2. ضبط إعدادات السيرفر وتفعيل خدمات DHCP وDNS. 3. إنشاء DHCP Pool مناسب لتوزيع عناوين IP والـ Subnet Mask وGateway وDNS Server على الأجهزة. 4. إعداد خدمة DNS بحيث يمكن اختبار تحليل أسماء النطاقات إلى عناوين IP. 5. ضبط إعدادات أجهزة الكمبيوتر الثلاثة لتستقبل عناوين الشبكة تلقائيًا. 6. اختبار الاتصال بين الأجهزة باستخدام الأمر ping، والتأكد من عمل الخدمات المطلوبة بشكل صحيح. التسليم: - ملف المشروع النهائي بصيغة .pkt قابل للفتح والتعديل عبر برنامج Cisco Packet Tracer، مع التأكد من صحة التوصيلات والإعدادات.
